# Salam Automobile — Interest Rate (TikTok 9:16)

Infographic motion video (2D, dark + gold, reference style) built with HyperFrames.
Audio = voiceover from `IMG_0005.MOV` only (cut to ~59 s), plus synthesised music & SFX.

- `index.html` — the composition (all scenes, karaoke captions, closing logo)
- `assets/audio/vo.wav` — edited voiceover (repeats/fillers removed, pauses tightened, 1.08x, cleaned & normalised)
- `assets/audio/music.wav`, `assets/audio/sfx.wav` — generated by `tools/audio_synth.py` (royalty free)
- `assets/img/*` — Salam Automobile logo split into parts for the closing animation
- `renders/salam-interest-rate.mp4` — final render

Re-render: `npx hyperframes render -o renders/salam-interest-rate.mp4 --quality high`
